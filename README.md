# Menezes Mêne

Site oficial do Ministério Menezes Mêne, com apresentação de serviços musicais, fotos e vídeos, informações de pagamento e canais de contato.

**Acesse:** [menezes-mene.netlify.app](https://menezes-mene.netlify.app/)

## Sobre o projeto

O site foi desenvolvido para apresentar o trabalho do Menezes Mêne e facilitar o contato de pessoas interessadas em shows, eventos e aulas. A página reúne a história visual do ministério, exemplos de apresentações e informações para solicitar um orçamento.

## Serviços apresentados

- Shows e apresentações musicais solo ou em grupo para eventos.
- Aulas de violão, guitarra e bateria.
- Aulas de inglês do Projeto Futuro.
- Informações de pagamento via Pix e outros métodos.

## Recursos do site

- Layout responsivo para celular e computador.
- Galeria de fotos com troca automática de slides e controles manuais.
- Vídeos e música para conhecer o trabalho do ministério.
- Formulário de contato e acesso direto ao WhatsApp.
- Download do aplicativo Android pelo ícone disponível no site.
- SEO básico, metadados para compartilhamento e dados estruturados.
- Fundos vetoriais em SVG e animações com suporte à preferência por movimento reduzido.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- SVG
- Hospedagem e publicação pelo Netlify

## Executar localmente

O projeto é estático e não requer etapa de compilação ou instalação de dependências.

1. Clone o repositório:

   ```bash
   git clone https://github.com/Alexsarantes2023/menezes-mene.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd menezes-mene
   ```

3. Abra `index.html` no navegador ou inicie um servidor local. Por exemplo, com Python:

   ```bash
   python -m http.server 8000
   ```

   Depois, acesse [http://localhost:8000](http://localhost:8000).
